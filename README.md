정적 웹페이지입니다.

| --- | --- |
| 여행 기간 | 2027년 2월 19일(금) ~ 2월 28일(일) |
| 현지 체류 | 8박 9일 (2/20 08:25 도착 ~ 2/28 10:20 출발) |
| 동선 | 시드니 IN / 시드니 OUT |
| 출국편 | 2/19(금) 20:00 인천 → 2/20(토) 08:25 시드니 (약 10시간 25분) |
| 귀국편 | 2/28(일) 10:20 시드니 → 2/28(일) 19:00 인천 (약 10시간 40분) |
| 구성원 | 성인 2명, 자녀 2명 (2018년생 남아 · 2020년생 여아) |

## 보는 방법

`index.html` 파일 하나로 끝납니다. 빌드나 설치 과정이 없습니다.

```bash
# 저장소를 받은 뒤 브라우저로 열기만 하면 됩니다
open index.html        # macOS
start index.html       # Windows
xdg-open index.html    # Linux
```

## GitHub Pages로 배포하기

1. 저장소 **Settings → Pages** 로 이동
2. **Source** 를 `Deploy from a branch` 로 두고
3. 배포할 브랜치와 `/ (root)` 폴더를 선택 후 저장

몇 분 뒤 `https://<사용자명>.github.io/trip-plan/` 에서 열립니다.

## 기능

- **플랜 탭** — 6가지 동선 안을 전환하며 비교. 마지막으로 본 안이 기억됩니다.
- **준비물 체크리스트** — 체크 상태가 브라우저에 자동 저장(localStorage)됩니다.
- **예산 계산기** — 플랜 / 등급 / 환율을 바꾸면 항목별 금액과 총액이 즉시 계산됩니다.
- **인쇄 / PDF 저장** — 체크리스트 버튼으로 종이 체크리스트를 뽑을 수 있습니다.
- **다크 모드** — 시스템 설정을 따르며, 우측 상단 버튼으로 수동 전환 가능합니다.
- **반응형** — 휴대폰 화면에서도 가로 스크롤 없이 동작합니다.
