# 시드니 가족여행 플래너 (2027.02.19 – 02.28)

4인 가족(부모 2 + 자녀 2)의 시드니 8박 여행 준비를 한 페이지에 정리한 정적 웹페이지입니다.
하버브리지 북단 키리빌리의 에어비앤비에 머물며 페리로 시내를 오가고, 근교 당일치기(블루마운틴, 포트 스티븐스)를 다녀옵니다.

**바로 보기: https://beyondlatent.github.io/trip-plan/**

## 보는 방법

`index.html` 파일 하나로 끝납니다. 빌드나 설치 과정이 없습니다.

```bash
# 저장소를 받은 뒤 브라우저로 열기만 하면 됩니다
open index.html        # macOS
start index.html       # Windows
xdg-open index.html    # Linux
```

## 배포

GitHub Pages가 `main` 브랜치 루트를 배포합니다. `main`에 머지되면 1분 안팎으로
https://beyondlatent.github.io/trip-plan/ 에 자동 반영됩니다.

## 기능

- **예비 숙소 조회 링크** — 에어비앤비가 취소될 때를 대비해 날짜·인원이 입력된 호텔 예약 조회 링크.
- **준비물 체크리스트** — 체크 상태가 브라우저에 자동 저장(localStorage)됩니다.
- **예산 계산기** — 지출 등급·환율·국제선·숙박 실제 결제액을 넣으면 항목별 금액과 총액이 즉시 계산됩니다.
- **인쇄 / PDF 저장** — 체크리스트 버튼으로 종이 체크리스트를 뽑을 수 있습니다.
- **다크 모드** — 시스템 설정을 따르며, 우측 상단 버튼으로 수동 전환 가능합니다.
- **반응형** — 휴대폰 화면에서도 가로 스크롤 없이 동작합니다.
